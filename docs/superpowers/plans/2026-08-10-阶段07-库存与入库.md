# 阶段 7：库存与入库模块 实施计划

> **For agentic workers:** 本阶段由主代理（/root）内联执行，按 executing-plans 流程分批实施、检查点验证。

**Goal:** 完成库存查询（含预警）、库存流水追溯、盘盈/盘亏调整，以及入库单全流程（草稿→审核→验收入账），库存变动全部经流水留痕。

**Architecture:** 库存增减使用原子 SQL（入库 `quantity + n`，盘亏 `quantity >= n` 条件更新）；验收入账与流水写入同事务；单据号 `RK{yyyyMMdd}{6位流水}` 由 Redis INCR 生成；库存预警条件 `quantity <= safe_stock`。

**Tech Stack:** MyBatis-Plus + 原子 UPDATE；前端库存/流水/入库单三个标准页面。
