# 阶段 3：登录认证模块 实施计划

> **For agentic workers:** 本阶段由主代理（/root）内联执行，按 executing-plans 流程分批实施、检查点验证。

**Goal:** 实现账号密码 + 图形验证码 + JWT + Redis 会话的完整登录认证链路（登录/登出/当前用户/改密），登录日志落库，前端可登录并持久化会话。

**Architecture:** Spring Security 6 无状态认证链（JwtAuthenticationFilter 解析 Bearer Token → Redis 会话校验 → SecurityContext）；验证码服务端生成存 Redis；登录成功写 `sys_login_log`；前端登录页 + Pinia userStore + 路由守卫。

**Tech Stack:** Spring Security 6、JJWT 0.12.x、Spring Data Redis（StringRedisTemplate + JSON）、Hutool 验证码；前端 Element Plus 表单 + Pinia。

## 验收标准

- [ ] 验证码接口返回 uuid + base64 图片，Redis 存有对应值
- [ ] admin/admin123 + 正确验证码登录成功，返回 token；登录日志落库
- [ ] 错误验证码 / 错误密码返回对应错误码（2002/2001）
- [ ] 携带 token 可访问 `/api/auth/info`；登出后同一 token 返回 401
- [ ] 前端登录页可完成登录并持久化 token；未登录访问受保护页跳转登录
- [ ] commit 5 提交（前后端认证）
