# 阶段 8：借用归还模块 实施计划

> **For agentic workers:** 本阶段由主代理（/root）内联执行，按 executing-plans 流程分批实施、检查点验证。

**Goal:** 完成借用单（申请→审核→领用→续借→取消）与归还单（登记→确认验收→逾期/损坏处理）全流程，库存锁定与回补同事务，逾期自动扫描。

**Architecture:** 申请提交即原子锁定库存（`locked_quantity += qty`，条件 `quantity - locked >= qty` 防超借）；领用发放扣在库并核销锁定；驳回/取消解锁；归还确认回补库存并写流水；逾期由每日定时任务标记，归还时按系统参数结算违约金。

**Tech Stack:** 原子 UPDATE + `@Transactional`；Spring `@Scheduled` 逾期扫描；前端借用/归还管理页。
