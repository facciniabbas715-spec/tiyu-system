# 体育器材管理系统 实施计划（主计划 / Master Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按设计文档交付一套可运行的企业级体育器材管理系统（Spring Boot 3.5 + Vue3 前后端分离），覆盖认证权限、器材档案、库存入库、借用归还、报废与统计全流程。

**Architecture:** 后端 Spring Boot 3.5.x（JDK 24）+ Spring Security + JWT + Redis + MyBatis Plus + MySQL 8.0，严格分层（Controller/Service/Mapper），统一 Result 响应与全局异常；前端 Vue3 + Vite + TS + Element Plus + Pinia，动态路由与按钮权限。库存变动全部由单据驱动并写流水，核心业务按 TDD 推进。

**Tech Stack:** Spring Boot 3.5.x、MyBatis Plus 3.5.x、MySQL 8.0、Redis、Druid、Knife4j、EasyExcel、Flyway；Vue3、Vite、TypeScript、Element Plus、Pinia、Vue Router、Axios、ECharts。

## 2. 全局约定

### 2.1 分支与提交

- 分支：`main`（发布稳定）、`develop`（日常集成）、`feature/<模块>`、`release/*`、`hotfix/*`。脚手架阶段直接在 `main` 上提交，进入阶段 2 前建立 `develop` 分支。
- Commit 格式：`<type>(<scope>): <subject>`，type ∈ feat/fix/docs/style/refactor/test/chore/perf。
- 每个任务结束一个 commit；commit 粒度与主计划阶段表对应。

### 2.2 后端约定

- 包根：`com.company.sportseq`；工程名 `sportseq-admin`；接口前缀 `/api`。
- 实体继承 `BaseEntity`（create_by/create_time/update_by/update_time + del_flag + 逻辑删除注解）；库存表额外含 `version` 乐观锁。
- 状态字段一律 TINYINT + 后端枚举类 + 字典表文案，禁止魔法数字。
- 写操作事务在 ServiceImpl 声明；库存更新用原子 SQL（`WHERE quantity >= ?` 且校验影响行数）。
- 统一响应 `Result<T>`（code/message/data/traceId）；业务异常抛 `BizException(ErrorCode, msg)`。
- 敏感参数（密码/token）日志脱敏。

### 2.3 前端约定

- 包管理器 npm；工程名 `sportseq-web`；路径别名 `@` → `src`。
- 页面结构：查询表单 + 表格 + 分页 + 工具栏；列表页统一使用 `useTable`。
- 状态/字典展示用 `<DictTag>`；按钮权限用 `v-permission`。
- 所有请求走 `src/api/request.ts` 封装（token 注入、401 跳转、错误提示、防重复提交）。

### 2.4 验证命令（每阶段必须执行）

```bash
# 后端：编译 + 测试 + 启动
cd sportseq-admin
./mvnw test
./mvnw spring-boot:run
curl http://localhost:8080/api/health

# 前端：类型检查 + 构建 + 开发服务器
cd sportseq-web
npm run type-check
npm run build
npm run dev
```

## 4. 风险与对策

| 风险 | 对策 |
| --- | --- |
| JDK 24 与三方库（Lombok/MyBatis-Plus）兼容性 | Spring Boot 3.5.x 管理版本；若 Lombok 注解处理报错，显式升级 lombok 至 1.18.38+ |
| Maven 未装导致无法构建 | 使用 Initializr 生成 + Maven Wrapper，`./mvnw` 独立可用 |
| Redis 无法安装（影响阶段 3 认证） | 阶段 0-1 不受影响；到阶段 3 时选项按序：Memurai → tporadowski/redis → WSL；若全部失败则回退开发期本地缓存实现（需评审 D1 决策） |
| MySQL root 密码未知 | 阶段 0 询问用户；建库与专用账号脚本在阶段 2 的 Flyway 前置步骤提供 |
| 计划与实现偏差 | 每阶段完成即回到主计划核对；偏差超过单阶段范围时先评审再继续 |
