# 阶段 4：权限管理模块 实施计划

> **For agentic workers:** 本阶段由主代理（/root）内联执行，按 executing-plans 流程分批实施、检查点验证。

**Goal:** 完成 RBAC 权限闭环：部门/用户/角色/菜单四类管理 CRUD、按钮级权限校验（`@PreAuthorize` + 前端 `v-permission`）、登录后动态路由与后台布局。

**Architecture:** 后端统一 `/api/system/**` 接口，权限注解基于 LoginUser.permissions；`getRouters` 按当前用户角色返回菜单树（M/C 节点），前端映射为动态路由；数据权限字段（data_scope）已入库，完整拦截器在业务阶段按需启用。

**Tech Stack:** Spring Security `@EnableMethodSecurity` + MyBatis-Plus；前端 Element Plus 布局组件（Sidebar/Navbar/TagsView）、Pinia permissionStore、`import.meta.glob` 动态组件映射。
