# 器材归还规则

## 归还流程

器材使用完毕后应及时到器材室办理归还。归还时管理员核对器材名称、数量与完好情况，创建归还单，归还单状态为：待确认 → 已确认 / 已驳回。管理员确认归还后，系统回补在库库存并记录库存流水，同时更新借用明细的归还数量。

## 逾期处理

未在预计归还日期前归还的器材会被系统标记为逾期。归还时系统按实际归还日期与预计归还日期的差值计算逾期天数，并按系统参数自动计算违约金（默认每件每天 5 元，金额可在归还确认前手工调整）。逾期记录会影响后续借用信用，请按时归还。

## 损坏与丢失

归还时如发现器材损坏或丢失，归还单会按损坏归还或丢失挂失类型登记，并按损坏处理规则核算赔偿金额，经管理员确认后计入归还单。

## 注意事项

归还单被驳回后需要重新办理；部分归还时系统只核销已归还的数量，剩余数量继续处于借用中状态。
