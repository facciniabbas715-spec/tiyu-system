# 篮球相关知识

## 篮球保养

篮球使用后应及时用干净的干布擦拭表面的灰尘与汗渍，避免使用腐蚀性清洁剂；不要用尖锐物体接触球面，避免在水泥地等粗糙地面长时间拍打。篮球应存放在干燥、阴凉、通风处，远离阳光直射、暖气与潮湿环境，防止表皮开裂、变形与开胶。

## 气压标准

标准 7 号篮球的气压一般应保持在 0.49~0.54MPa 之间，充气后从约 1.8 米高度自由落下，反弹高度约为 1.2~1.4 米为宜。充气不足会降低弹性并损伤内胆，充气过足易爆裂，请使用带气压表的气针并少量多次充气。

## 使用常识

比赛用球通常为 7 号球，青少年训练可使用 5 号、6 号球。篮球场地应平整、防滑；运动前充分热身，运动中注意保护手腕与脚踝。篮球为易耗器材，出库与归还时请核对数量并检查表面完好情况。
