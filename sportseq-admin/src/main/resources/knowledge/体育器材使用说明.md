# 体育器材使用说明

## 使用前检查

使用任何体育器材前，请先检查器材外观是否完好：确认无松动、开裂、变形、锈蚀等异常，检查连接部位与紧固件是否到位。发现异常应立即停止使用并联系器材管理员报修，不得带病使用。

## 使用中注意事项

使用过程中应遵守器材的额定承重与标准使用方式，禁止超负荷、超范围使用；多人共用时应注意秩序与安全，避免发生碰撞。球类器材应避免在尖锐、粗糙的地面上拍打或拖拽，防止划伤表皮。

## 使用后归位

使用完毕后请清理器材表面的汗渍与灰尘，将器材放回指定存放位置，保持场地整洁。发现器材损坏或丢失时，应第一时间向器材管理员报告，并配合完成损坏登记。

## 安全提示

未成年人使用健身类器材时应有教师或家长监护；雷雨、大风等恶劣天气下不得在室外使用金属类器材。出现头晕、胸闷等身体不适时应立即停止运动并求助。
