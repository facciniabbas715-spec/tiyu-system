# 器材损坏处理规则

## 损坏认定

借用或使用过程中造成器材损坏、丢失的，由器材管理员在归还环节进行损坏认定，记录损坏部位、损坏程度与责任说明，并拍照留档。

## 赔偿标准

损坏赔偿按以下原则核定：可修复的按维修成本赔偿；不可修复或丢失的按器材当前净值（原值扣除折旧）赔偿；球类、拍类等易耗器材可按市场价格核定。具体金额由管理员在归还单中登记，并可结合责任认定结果适当调整。

## 处理流程

损坏归还单经管理员确认后，赔偿金额计入归还单；若器材已无法继续使用，可发起报废申请，报废单经审核与处置后从库存中扣减。故意损坏器材的，按学校或单位相关管理规定追加处理。

## 免责情形

因器材自然老化、正常磨损导致的问题不属于人为损坏，使用人无需承担赔偿，由管理员按维护或报废流程处理。
