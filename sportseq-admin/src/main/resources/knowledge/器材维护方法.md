# 器材维护方法

## 日常维护

1. 球类：使用后用干布擦拭表面灰尘与汗渍，检查气嘴是否漏气；篮球、足球保持标准气压，存放于干燥阴凉处，避免阳光暴晒、潮湿与尖锐物体划伤。
2. 球拍类：羽毛球拍、网球拍使用后检查拍线与拍框，收纳于拍套中，避免重压与高温。
3. 金属器械：定期检查焊点、螺丝与连接件，发现松动及时紧固，生锈部位除锈并补漆。
4. 垫子与护具：保持干燥清洁，定期晾晒，破损及时修补或更换。

## 定期保养

每学期对器材进行一次全面检查与保养：校核球类气压与外观，润滑器械活动部件，更换老化配件，更新器材状态与安全库存信息。保养记录应登记到系统，便于追溯。

## 存放要求

器材应按分类上架存放，做到防潮、防压、防晒、防尘；贵重与危险器材专柜存放。器材室应保持通风干燥，定期盘点，确保账实一致。
