# 体育器材分类说明

## 分类体系

系统按运动项目与用途对器材进行树形分类管理，例如：球类（篮球、足球、羽毛球、乒乓球、网球等）、田径器材、体操器材、健身器材、护具与配件等。每个分类有唯一分类编码，器材编号以分类编码为前缀生成，便于识别与统计。

## 分类管理

分类支持多级树形结构，管理员可新增、修改、停用分类；存在子分类的分类不可直接删除，存在器材档案的分类在器材清理前不可删除。分类状态分为正常与停用，停用分类下不再新增器材。

## 使用场景

器材档案、库存、入库、借用、统计均按分类组织：库存预警按分类查看，统计报表按分类汇总库存数量与价值，方便学校或单位掌握各类器材的配置与消耗情况。
