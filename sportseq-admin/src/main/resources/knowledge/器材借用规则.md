# 器材借用规则

## 借用流程

借用器材需在系统中提交借用申请，选择所需器材与数量，并填写预计归还日期与借用用途。提交申请后系统会锁定对应库存数量，防止他人超借；管理员审核通过后，申请人凭借用单到器材室领用。

## 审核与领用

借用申请状态依次为：待审核 → 已通过待领用 → 借用中 → 部分归还 → 已全部归还；申请也可被驳回或取消。审核驳回或取消申请时，系统自动释放锁定的库存。审核通过后由管理员发放领用，发放时核销锁定库存并扣减在库数量。

## 续借

借用中的器材如需延长使用时间，可在系统中申请续借，延长预计归还日期；续借需要管理员审批，审批通过后生效，系统会记录累计续借次数。

## 注意事项

每位用户同时未归还的借用数量与单次借用数量受系统规则限制；易耗器材、大型器材等可能另有专项审批要求，请以管理员发布的规则为准。
